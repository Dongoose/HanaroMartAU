# 와규 재고 체크

팀원이 Teams 링크로 매장 내 와규 갯수와 시스템 상의 재고(kg)를 입력하면, 구글 시트가 서버 시각(브리즈번)과 함께 기록하고 갯수 × 평균 무게를 시스템 kg과 비교해요. 한 개쯤(±0.10 kg 이상) 차이 나면 빨간불이 들어오고, 직전 카운트와 CCTV 확인 구간도 붙어요. Google Apps Script 웹 앱이고, 지금은 와규 한 품목만 세요.

| 파일 | 붙여넣을 곳 |
| --- | --- |
| `apps-script/Code.gs` | Apps Script의 `Code.gs` |
| `apps-script/Index.html` | Apps Script에 새로 만든 HTML 파일 `Index` |

설치 순서, 폰 화면 미리보기, 복사 버튼은 `index.html`(설치 안내 페이지)에 있어요. 웹 주소(`…/meat-stock/`)로 열어야 미리보기와 복사가 동작해요.

짧게: 새 구글 시트 → 확장 프로그램 → Apps Script → 두 파일 붙여넣기 → `setup` 한 번 실행 → 배포 → 웹 앱(실행: 나, 액세스: 모든 사용자) → Settings 탭에서 Manager PIN 바꾸기.

코드를 바꿀 때는 두 파일을 다시 붙여넣고 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 링크는 그대로예요.

화면
- 맨 위 초록 바: ‹ › 이전·다음 화면, 로고·제목이나 집 버튼을 누르면 첫 화면(개수 입력).
- 매니저 화면 맨 아래 **Reset all data**: "Are you sure…?"에서 한 번 더 확인하면 Log 기록을 전부 지워요. 실수로 지웠다면 시트의 파일 → 버전 기록에서 되돌릴 수 있어요.
- 첫 화면: ① 와규 갯수(매장 내 보유 갯수 입력), ② System stock(시스템 상의 재고 입력, kg). 맞는지 여부는 팀원 화면에 안 보여줘요.
- Log 탭: 센 갯수 × 평균 무게와 시스템 kg이 `Red when off by (kg)` 이상 차이 나면(부족·초과 모두) 차이 칸이 빨갛게 표시돼요.
- 이전 버전에서 바꾸면 페이지를 처음 열 때 기존 Log가 `Log (old)`로 보관되고 새 Log가 생겨요. 평균 무게가 처음 값(0.1425) 그대로면 0.1455로 바뀌어요.

Settings 탭

| 줄 | 기본값 | 뜻 |
| --- | --- | --- |
| Manager PIN | 1234 | 매니저 화면 PIN. 10번 틀리면 15분 잠김 |
| Avg kg per unit | 0.1455 | 와규 한 개 평균 무게(kg). 11월 4일 19개 2.764 kg ÷ 19 |
| Red when off by (kg) | 0.1 | 이만큼 이상 차이 나면 빨간불 (한 개 ≈ 0.145 kg) |
| Price per kg | 비어 있음 | 넣으면 차이가 $로도 나와요 |
| Page title | Wagyu Stock Check | 화면 맨 위 제목 |
