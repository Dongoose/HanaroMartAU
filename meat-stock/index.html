와규 재고 체크

팀원이 Teams 링크를 눌러 로그인 없이 와규 개수를 입력하면, 구글 시트에 초 단위 시각과 대략적인 kg이 쌓여요. 매니저가 있어야 할 개수를 넣으면 차이와 CCTV 확인 구간이 바로 나와요.

설치 10분 정도 노트북에서 하기 추천 구글 계정만 있으면 무료

팀원 폰에 뜨는 화면

미리보기를 불러오는 중…

아래 Index.html을 그대로 띄운 화면이에요. 저장, 매니저 화면(PIN 1234)까지 눌러볼 수 있고, 여기 입력한 건 저장되지 않아요. 기록은 예시예요.

팀원
  • 와규 개수 하나만 입력해요. 숫자를 치거나 +/−로 맞춘 뒤 저장.
  • 이름은 한 번만 쓰면 그 폰에 기억돼요.
  • 진열 보충, 입고, 폐기는 메모에 한 줄.
  • 이전 개수는 안 보여줘요. 보고 따라 적는 걸 막으려고요.
시트
  • 저장 시각은 폰이 아니라 서버 시계로 초까지 찍혀요 (브리즈번 시간).
  • 개수 × 개당 평균 무게(기본 0.1425 kg)로 대략 kg 자동 계산.
  • 직전 카운트의 개수와 시각을 찾아 변동을 붙여요.
매니저
  • 같은 링크 하단 Manager → PIN 입력.
  • 기록마다 있어야 할 개수(POS, 입고 기준)를 넣으면 차이가 개수, kg, $로 나와요.
  • 상단에 부족분 합계, 아래는 날짜별 기록.

차이 = 카운트 − 매니저 재고
−2 이면 2개가 비는 것. CCTV는 직전 카운트 시각 → 이번 카운트 시각 사이를 보면 돼요.

Setup

설치 순서

  1. 새 구글 시트 만들기

    브라우저 주소창에 sheets.new 입력. 이름은 "Wagyu Stock Check" 정도로.

  2. Apps Script 열고 Code.gs 붙여넣기

    시트 메뉴 확장 프로그램 → Apps Script (영어: Extensions → Apps Script). 열린 Code.gs 안의 기존 내용을 지우고, 아래 Code.gs 복사 버튼으로 복사한 걸 붙여넣어요.

  3. HTML 파일 "Index" 추가

    왼쪽 파일 목록의 + → HTML. 이름을 정확히 Index로 (대문자 I, 확장자는 자동). 안의 내용을 지우고 Index.html 복사한 걸 붙여넣은 뒤 저장(Ctrl/Cmd + S).

  4. setup 한 번 실행

    상단 함수 선택칸에서 setup 고르고 실행. 권한 창이 뜨면 본인 계정 선택 → 고급 → (안전하지 않은 페이지)로 이동 → 허용.

    본인이 만든 스크립트라 구글이 "확인되지 않은 앱"이라고 띄우는 거예요. 시트에 Log, Settings 탭이 생기면 성공.

  5. 웹 앱으로 배포

    배포 → 새 배포 → 유형 선택 톱니바퀴 → 웹 앱. 아래처럼 설정하고 배포.

    • 다음 사용자 인증 정보로 실행: 나 (Execute as: Me)
    • 액세스 권한이 있는 사용자: 모든 사용자 (Who has access: Anyone)

    "Google 계정이 있는 모든 사용자"가 아니라 "모든 사용자"여야 팀원이 로그인 없이 들어와요.

    나오는 웹 앱 URL(…/exec로 끝나는 주소)을 복사.

  6. Settings 탭 정리

    • Manager PIN: 1234에서 꼭 바꾸기.
    • Avg kg per unit: 와규 한 개 평균 무게. 0.1425로 들어가 있어요.
    • Price per kg(선택): 넣으면 차이가 $로도 나와요.

    시트에서 바꾼 건 재배포 없이 바로 반영돼요. 이미 저장된 줄은 저장 당시 무게와 가격을 그대로 유지해요.

  7. Teams에 고정

    채널 상단 + → 웹사이트 탭으로 URL 추가하거나, 게시물로 올리고 고정. 팀원은 누르기만 하면 돼요.

    처음 열면 맨 위에 "Google Apps Script 사용자가 만든 앱" 회색 문구가 보이는데 정상이에요.

운영하면서 알아둘 것

    

    
    
      
  • 팀원은 링크로 입력만 할 수 있고 기존 기록을 고치거나 지울 수 없어요. 시트 자체는 본인과 매니저에게만 공유하세요.
    • 
      
  • 폰 시계를 바꿔도 기록 시각은 서버 기준이라 영향이 없어요.
    • 
      
  • 진열 보충이나 입고 직후 카운트는 메모가 있어야 변동이 설명돼요. 메모 없이 개수가 줄었는데 POS 판매량보다 많이 줄었다면 그 구간이 CCTV 후보예요.
    • 
      
  • 매니저 PIN은 10번 틀리면 15분 잠겨요. 가벼운 잠금이라 PIN은 팀 채팅에 올리지 마세요.
    • 
      
  • 코드를 고칠 일이 생기면 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포. 링크는 그대로 유지돼요.
    • 
      
  • 예전 여러 품목 버전을 이미 설치했다면 두 파일을 이 코드로 바꾸고 setup을 한 번 더 실행한 뒤 새 버전으로 배포하세요. 기존 Log는 그대로 쓰고, Settings에 무게와 가격 줄이 추가돼요. Products 탭은 지워도 돼요.
    • 
      
  • 지금은 와규 전용 화면이에요. Log에 Product 열을 남겨 둬서 나중에 품목을 늘려도 기존 기록을 그대로 쓸 수 있어요.
