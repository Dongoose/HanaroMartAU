정육 재고 체크

팀원이 Teams 링크를 눌러 로그인 없이 품목마다 매장에 있는 갯수와 시스템에 나온 재고를 입력하면, 시트가 둘을 맞춰 보고 한 개쯤 차이 나면 빨간불을 켜요. 지금은 와규(시스템 kg), 냉장 삼겹살(시스템 갯수), 와규 국거리(매장 재고 없음 · 나중에 확인) 3품목이에요.

설치 10분 정도 노트북에서 하기 추천 구글 계정만 있으면 무료

팀원 폰에 뜨는 화면

미리보기를 불러오는 중…

아래 Index.html을 그대로 띄운 화면이에요. 저장, 매니저 화면(PIN 1234)까지 눌러볼 수 있고, 여기 입력한 건 저장되지 않아요. 기록은 예시예요.

팀원
  • 품목 카드마다 ① 매장 내 보유 갯수, ② 시스템 상의 재고(와규는 kg, 삼겹살은 개)를 넣고 한 번에 저장. 센 품목만 입력하면 돼요.
  • 와규 국거리는 "확인 필요"로 접혀 있어요. 재고가 생기면 "지금 입력하기"로 열어서 입력.
  • 이름은 한 번만 쓰면 그 폰에 기억돼요. 진열 보충, 입고, 폐기는 메모에 한 줄.
  • 맞는지 틀리는지는 팀원 화면에 안 보여줘요. 시스템 숫자에 맞춰 갯수를 적는 걸 막으려고요.
  • 맨 위 ‹ › 화살표로 이전·다음 화면. 집 모양 버튼이나 로고·제목을 누르면 첫 화면(개수 입력)으로 가요.
시트
  • 저장 시각은 폰이 아니라 서버 시계로 초까지 찍혀요 (브리즈번 시간).
  • Products 탭에 품목별 단위, 개당 무게, 빨간불 기준을 적어 둬요.
  • 와규: 센 갯수 × 0.1455 kg을 시스템 kg과 비교해 ±0.10 kg 이상이면 빨간불. 냉장 삼겹살: 갯수끼리 비교해 1개라도 다르면 빨간불.
  • 품목마다 직전 카운트의 갯수와 시각을 찾아 변동을 붙여요.
매니저
  • 같은 링크 하단 Manager → PIN 입력.
  • 입력할 건 없어요. 맨 위에 품목별 최근 상태, 그 아래 품목 칩으로 골라 보기.
  • 한 번에 저장한 기록은 한 카드로 묶여요. 품목마다 센 갯수, 시스템 재고, 차이와 빨간불.
  • 맨 아래 Reset all data: "Are you sure…?"에서 한 번 더 확인하면 Log 기록을 전부 지우고 새로 시작해요.

와규: 센 갯수 × 0.1455 − 시스템 kg → ±0.10 kg 이상 빨간불
삼겹살: 센 갯수 − 시스템 갯수 → 1개 이상 빨간불
CCTV는 직전 카운트 시각 → 이번 카운트 시각 사이를 보면 돼요.

Setup

설치 순서

  1. 새 구글 시트 만들기

    브라우저 주소창에 sheets.new 입력. 이름은 "Wagyu Stock Check" 정도로.

  2. Apps Script 열고 Code.gs 붙여넣기

    시트 메뉴 확장 프로그램 → Apps Script (영어: Extensions → Apps Script). 열린 Code.gs 안의 기존 내용을 지우고, 아래 Code.gs 복사 버튼으로 복사한 걸 붙여넣어요.

  3. HTML 파일 "Index" 추가

    왼쪽 파일 목록의 + → HTML. 이름을 정확히 Index로 (대문자 I, 확장자는 자동). 안의 내용을 지우고 Index.html 복사한 걸 붙여넣은 뒤 저장(Ctrl/Cmd + S).

  4. setup 한 번 실행

    상단 함수 선택칸에서 setup 고르고 실행. 권한 창이 뜨면 본인 계정 선택 → 고급 → (안전하지 않은 페이지)로 이동 → 허용.

    본인이 만든 스크립트라 구글이 "확인되지 않은 앱"이라고 띄우는 거예요. 시트에 Log, Settings 탭이 생기면 성공.

  5. 웹 앱으로 배포

    배포 → 새 배포 → 유형 선택 톱니바퀴 → 웹 앱. 아래처럼 설정하고 배포.

    • 다음 사용자 인증 정보로 실행: 나 (Execute as: Me)
    • 액세스 권한이 있는 사용자: 모든 사용자 (Who has access: Anyone)

    "Google 계정이 있는 모든 사용자"가 아니라 "모든 사용자"여야 팀원이 로그인 없이 들어와요.

    나오는 웹 앱 URL(…/exec로 끝나는 주소)을 복사.

  6. Settings · Products 탭 정리

    • Settings → Manager PIN: 1234에서 꼭 바꾸기.
    • Products: 품목마다 System unit(kg / pcs), Avg kg per piece(kg 품목만), Red when off by, Price(선택), Status가 있어요.
    • 와규: kg, 0.1455 kg(11월 4일 19개 2.764 kg ÷ 19), ±0.1. 냉장 삼겹살: pcs, ±1.
    • 와규 국거리: Status가 Check later예요. 재고가 들어오면 몇 개 재서 Avg kg per piece를 넣고 Active로 바꾸세요. 시스템이 갯수로 나오면 System unit을 pcs로.
    • 새 품목은 Products 탭에 줄을 더하면 되고, 그만 셀 품목은 Status를 Off로.

    시트에서 바꾼 건 재배포 없이 바로 반영돼요. 이미 저장된 줄은 저장 당시 무게, 기준, 가격을 그대로 유지해요.

  7. Teams에 고정

    채널 상단 + → 웹사이트 탭으로 URL 추가하거나, 게시물로 올리고 고정. 팀원은 누르기만 하면 돼요.

    처음 열면 맨 위에 "Google Apps Script 사용자가 만든 앱" 회색 문구가 보이는데 정상이에요.

  • 팀원은 링크로 입력만 할 수 있고 기존 기록을 고치거나 지울 수 없어요. 시트 자체는 본인과 매니저에게만 공유하세요.
    • 
      
  • 폰 시계를 바꿔도 기록 시각은 서버 기준이라 영향이 없어요.
    • 
      
  • 진열 보충이나 입고 직후 카운트는 메모가 있어야 변동이 설명돼요. 메모 없이 개수가 줄었는데 POS 판매량보다 많이 줄었다면 그 구간이 CCTV 후보예요.
    • 
      
  • 매니저 PIN은 10번 틀리면 15분 잠겨요. 가벼운 잠금이라 PIN은 팀 채팅에 올리지 마세요.
    • 
      
  • 코드를 바꿀 때는 두 파일을 붙여넣고 저장한 뒤 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포. 링크는 그대로 유지되고, 시트의 빨간 표시 규칙은 다음에 페이지를 열 때 자동으로 새로 맞춰져요.
    • 
      
  • Reset으로 지운 기록은 시트의 파일 → 버전 기록에서 지우기 전 버전을 열어 되돌릴 수 있어요.
    • 
      
  • 와규만 세던 버전에서 바꾸면, 새 버전으로 배포한 뒤 페이지를 처음 열 때 Products 탭이 생기고(와규 무게, 빨간불 기준, 가격은 Settings에서 옮겨져요) 기존 Log는 그대로 이어서 써요. 기존 와규 줄에는 단위(kg)와 빨간불 기준이 채워지고, 제목이 Wagyu Stock Check였다면 Meat Stock Check로 바뀌어요.
    • 
      
  • 매니저가 재고를 넣던 첫 버전의 Log는 Log (old)로 이름이 바뀌어 보관돼요.
    • 
      
  • 품목을 늘리거나 줄이는 건 Products 탭에서 해요. 코드는 안 고쳐도 돼요.
